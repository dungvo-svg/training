# Lớp học NNC — plugin `lop-hoc`

Bục giảng (giao diện lớp học trên Claude Code Desktop) và giáo viên (Skill `lop-hoc:work-first-learning`) trong một plugin, không kèm OSER. Cài theo `CAI-DAT.md` ở gốc repo: Claude tự cài vào một thư mục lớp, tự cập nhật từ nhánh `main`.

Plugin không mang địa chỉ hay mã nhận góp ý, không mang dữ liệu học viên. Giao diện trên Claude Desktop cần buổi thử thật (`docs/VALIDATION.md`).
